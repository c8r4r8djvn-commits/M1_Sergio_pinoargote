## Prompt 1
**Lo que pedí:** Que me explicara paso a paso cómo crear una paleta de colores, con lenguaje sencillo.
**Para qué:** Entender cada línea de código en vez de copiarla.
**Qué aprendí:** La diferencia entre Git y GitHub, y para qué sirve `defer`.
## Prompt 2
**Lo que pedí:** Ayuda porque ejecuté `git init` y salió "Reinitialized existing Git repository".
**Para qué:** Entender si había roto algo.
**Qué aprendí:** Lo había ejecutado en la carpeta equivocada. Ahora uso `pwd` para comprobar dónde estoy antes de usar Git.

## Prompt 3
**Lo que pedí:** Que me explicara qué significaba lo que salió en `git status`.
**Para qué:** Saber por qué Git decía que README.md estaba "deleted".
**Qué aprendí:** Que "untracked" son archivos que Git todavía no vigila, y que mover un archivo Git lo ve como borrarlo de un lugar y crearlo en otro.
